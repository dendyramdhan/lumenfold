# Lumenfold

A pointer kaleidoscope. Move, and the stroke folds into symmetric light.

- Segments from 3 to 16
- Color modes: Prism, Jewel, Ember, Tide, Ash
- Reflect on or off
- Freeze the frame, randomize a new pattern, clear, or save a PNG

Shortcuts: Space freeze, R random, M reflect, E save, C clear.
